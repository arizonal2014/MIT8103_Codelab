# MIT 8103 Advanced Database Systems Codelab

[Start the step-by-step tutorial](01_Create_Your_Repository.md).

This step-by-step guide helps you complete the MIT 8103 continuous assessment. Choose a case study, use it for all five portfolio activities, and save evidence of your work as you go.

## What you will produce

The assessment is worth 40 marks. You will submit practical database work and a short summary.

| Component | Required work and evidence | Marks |
| --- | --- | ---: |
| Portfolio 1: Database Design and Modelling | Case-study description, ER diagram, relational schema, keys, constraints and normalisation explanation | 7 |
| Portfolio 2: Query Processing and Optimisation | SQL queries, results, execution plans, optimisation evidence and a brief performance analysis | 7 |
| Portfolio 3: Transactions and Concurrency | Commit, rollback, isolation and a concurrency issue or control mechanism, supported by outputs or screenshots | 7 |
| Portfolio 4: NoSQL and Advanced Data Models | A NoSQL model for the same case study, implementation evidence and an explanation of suitability | 7 |
| Portfolio 5: Distributed and Cloud Database Exercise | A case-related discussion or setup covering relevant concepts such as replication, sharding, availability, consistency or deployment | 6 |
| Final documentation | A 2–3-page summary covering the activities, selected case study, GitHub link, evidence, individual reflection, references and AI-use declaration where applicable | 6 |
| Total | | 40 |

Source: Sections 3 and 4 of the [assessment brief](https://lms-assets.miva.university/course-materials/mit-8103-advanced-database-systems-ca-september-cohort-2026.pdf).

## Before you begin

You will need:

- A computer with a browser and a reliable internet connection.
- A GitHub account. If you do not have one, [create an account](https://github.com/signup).
- The assessment question document.
- Your preferred AI assistant, if you want to use the prompts provided in this guide.

GitHub is a website for storing project files and keeping a history of changes. Your assessment repository is the project folder you keep on GitHub. We will create it together and save your work in stages.

Database setup is covered later. We will use PostgreSQL in GitHub Codespaces, a browser-based workspace. You can also use an existing PostgreSQL connection.

## How to follow the steps

1. Read the task and its assessment requirement.
2. Follow the instructions using your own case study. Replace the placeholders in any prompts you use.
3. Run the commands where indicated and check the results.
4. Save the scripts, outputs and screenshots requested in that step.
5. Save your progress to GitHub at each checkpoint.

Work through one step at a time. Use your actual results when explaining what happened.
